HDR Avatar Size & Crop Guide

Crop it once. Upload it everywhere. Keep the glow. Here are the sizes that won’t betray you.

Quick Specs

Recommended Size: 1000 x 1000 px (Universal)

Format: Indexed PNG (Color Type 3, 8-bit)

Color Profile: Rec.2020 PQ (Required for glow)

Safe Crop: Center-weighted (Keep faces in the middle)

IMPORTANT: Flashblind exports an indexed PNG (8-bit) with a Rec.2020 PQ ICC profile. This format ensures maximum glow with minimal file size.

Platform Notes

  • X / Twitter: Supports HDR fully. 1000x1000px is ideal. Avoid files larger than 10MB to prevent heavy re-compression.
  • Instagram: Strict cropping. Ensure your subject is perfectly centered 1:1. Glow works best on darker backgrounds.
  • Threads: Syncs with Instagram. Follow the same 1:1 square ratio rules.
  • Facebook: Aggressive compression. Upload via mobile "Upload HD" settings if available for best results.
  • Discord: Max file size 8MB (Free). Flashblind's indexed PNGs are efficient and usually fit this limit easily.

Mini FAQ

Can I resize the image?

Only if your software preserves the Rec.2020 PQ ICC profile. Most standard editors discard it, killing the glow. It is safer to upload the Flashblind export directly.

Why isn't it 16-bit?

Flashblind uses a specialized 8-bit indexed color palette. This mimics 10-bit or 16-bit HDR visual quality while keeping the file size small enough for social media uploads.

Why does the glow disappear on upload?

The platform may have stripped the ICC profile. Ensure you are uploading the original PNG from Flashblind, not a screenshot or a re-saved version.
