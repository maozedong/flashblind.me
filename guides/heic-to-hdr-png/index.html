Why HEIC loses its "Glow"

iPhone photos (HEIC) contain an internal "gain map" that tells the screen which pixels should be brighter than standard white. When you use a standard converter to make a JPG or PNG, this map is often discarded or flattened (tone-mapped) into Standard Dynamic Range (SDR).


Flashblind reads the raw pixel data and remaps it directly to the Rec.2020 PQ color space, preserving the luminance information compatible with X, Discord, and HDR monitors.

Best Export Settings

Flashblind applies these automatically for maximum compatibility:

  • Indexed PNG (Color Type 3) Essential for file size efficiency and broad platform support.
  • 8-bit Depth Ensures the file renders correctly on browsers that struggle with 16-bit PNGs.
  • Rec.2020 PQ ICC Profile The specific signal that triggers the "HDR mode" on displays.
  • Median-cut + Floyd-Steinberg Dithering Prevents color banding while maintaining a small file size.
